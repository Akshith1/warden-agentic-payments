# Phase 8 live run (November 2026)

Per-agent gateway keys, routes and budgets on the same Windows 11 machine,
with real models. Everything below comes from PowerShell and the console;
nothing is reconstructed.

## Replacing the public secrets

Before this phase `.env.example` shipped ready-made local secrets, so they
were public in this repository. The machine's `.env` still had three of them:

```
PS> Select-String -Path .env -Pattern "LITELLM_MASTER_KEY=sk-Tt8W", "LEDGER_WRITE_KEY=aKjIiH", "VENDOR_LOOKUP_KEY=K79ucb"
.env:17:LITELLM_MASTER_KEY=sk-Tt8W...
.env:20:LEDGER_WRITE_KEY=aKjIiH...
.env:21:VENDOR_LOOKUP_KEY=K79ucb...
```

They were emptied and refilled with `infra/scripts/fill-secrets.py`, and the
stack was recreated. All published ports now listen on 127.0.0.1 only.

## One invoice, five agents, five keys

Signed in as `amira`, a Brightline invoice for MYR 92.00 (`BOS-10811`) was
submitted. Every agent called the gateway with its own key:

```
1 Guardrail screened the text        2:17:54 PM          No instructions to the AI found by the rules or the safety model
2 Extraction agent read the invoice  2:17:56 PM +1.5 s   Prompt v3, promoted by the evaluation gate
3 Risk agent scored it               2:17:57 PM +1.5 s   low risk (0.28)
4 Approval agent decided             2:18:03 PM +5.5 s   auto approve, 92% sure
5 Critic agent reviewed the decision 2:18:04 PM +1.4 s   Objected: Remit-to account is missing; cannot verify
                                                         payment destination against the vendor's known account.
```

The critic's objection sent the run to a person.

## What each agent used

The Governance page's "Model use by agent, today" afterwards:

| Agent | Routes it may use | Calls | Tokens of daily budget | Cost |
| --- | --- | --- | --- | --- |
| guardrail | warden-guardrail | 1 | 878 of 400,000 | $0.0001 |
| extraction | warden-routine | 1 | 1,719 of 400,000 | $0.0005 |
| risk-scoring | warden-routine, warden-reasoning | 1 | 1,411 of 400,000 | $0.0005 |
| approval | warden-reasoning | 1 | 1,347 of 300,000 | $0.01 |
| critic | warden-routine | 1 | 1,646 of 300,000 | $0.0005 |
| eval-gate | warden-routine | 0 | 0 of 600,000 | |

About 7,000 tokens and roughly one cent per invoice. The approval agent on
the reasoning route uses fewer tokens than extraction but costs the most:
it is the only call on the reasoning model below the routine amount, which
is why only that decision goes there. LiteLLM priced both real models, so
the costs are filled in.

## Not yet run on the machine

The refusals (a route outside the agent's list, an agent over its budget, a
paused agent's model calls) were tested against a running LiteLLM 1.106.5
with mock models before shipping. To see the budget refusal live, lower one
agent's `daily_tokens` in `infra/litellm/agents.yaml` and rebuild `litellm`.
